# cwdprobe v0.1.0

First public version of a small Windows cwd compatibility experiment runner.
Run one trusted executable command across ASCII, Chinese, Japanese, Korean,
space and valid punctuation directories, with two fresh runs per case by default.

- Text/JSON reports: exit states, timings, raw stdout/stderr prefixes, hashes
  and strict decoding diagnostics.
- Conservative distinction between general failure, path-sensitive failure,
  output differences, incomplete execution and tool errors.
- Windows Job Object lifecycle handling, bounded capture and owned-directory
  cleanup, with startup/cleanup interruption regression coverage.
- Standard-library runtime, MIT license. No server, paid API or telemetry.

Verified profile: **Windows 11 x64; native CPython 3.11 and 3.12**.
The 42-test suite passes on both local interpreters. Hosted Windows CI is
prepared but **NOT TESTED** until actually run on GitHub; no green CI is claimed.

Assets: `cwdprobe-0.1.0.pyz`, `SHA256SUMS.txt`, `LICENSE`.
**The pyz requires Python; it is not a standalone EXE.**

Limits: trusted commands only, not a security sandbox. Cwd variation does not
simulate accounts/profiles, TEMP/TMP, executable/project relocation or system
codepage changes. Path sensitivity is not an encoding root-cause diagnosis.
Reports can contain private paths/arguments/output and stay local. Windows 10,
ARM64, Python 3.13+, real third-party bug reproductions, forced-kill cleanup and
particular terminal keyboard/close-window behavior remain NOT TESTED.
